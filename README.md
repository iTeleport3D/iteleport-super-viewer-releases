# iTeleport Super Viewer — Windows releases

Official portable Windows downloads and signed update manifests for iTeleport Super Viewer.

Download **iTeleport-Super-Viewer.exe** from the latest release. No installation is required. The source code is maintained separately in a private repository.

Starting with version 5.8.0, use **Updates → Check for updates…** inside the viewer. Automatic checks can be enabled or disabled from the same menu. Updating requires confirmation, verifies signed release metadata, and preserves the executable location and existing preferences.

Versions older than 5.8.0 require one manual download to enable future automatic updates.
